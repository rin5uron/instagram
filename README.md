# SNS×AI 自立プロジェクト

管理栄養士×IT×AIの掛け合わせで、自分のスキルと発信で稼ぐ道を作るプロジェクト。

---

## 背景

新卒から保育園の管理栄養士として働く中で、アナログな現場・デジタル化の遅れ・人手不足の構造的な問題を目の当たりにした。体一つで現場を支えるのではなく、ITで仕組みをつくることで業界を根本から支えたいと感じた。この業界の将来性を案じると同時に、後輩指導や現場マネジメントより「一つのことを積み上げて何かをつくる仕事」への適性を実感し、2025年12月に退職を決意。

プログラミング学習を続けながら、アフィリエイトサイト制作やアプリ開発のマネタイズ設計を進める中で、マーケティングやSNS運用の大切さを実感。2026年4月、インスタを通じてSNS運用・マーケティング・AIスキルを本格的に学ぶことを決め、このプロジェクトを開始した。

---

## アカウント

最初は管理栄養士としてのE-E-A-Tを確立しブランドにつなげる1アカウント運用を想定していた。しかし、マネタイズ設計と対象視聴者を見直した結果、AIスキル発信に軸足を移した。ただし管理栄養士としてのブランド力・撮影技術の獲得も並行して行いたいため、2アカウント同時運行中。マネタイズの方向性と視聴者ベネフィットは両アカウントで統一している。

| | [@ringo__note](https://www.instagram.com/ringo__note/) | [@ringonote_ai](https://www.instagram.com/ringonote_ai/) |
|---|---|---|
| テーマ | 栄養士×AI×食生活 | AI実験×検証 |
| コンセプト | ニートになった管理栄養士が、生活を崩さないためにGPTにごはんを丸投げするリアル記録 | AIに任せて、自分の時間を取り戻す実験中 |
| 視聴者ベネフィット | AIを使えば生活が整うかもと気づける・管理栄養士監修で信頼できる・自分でも真似できる | AIツールの使い方がわかる・自分でも試せる・時間を節約できる |
| マネタイズ | アフィリエイト・SNS運用代行・コンテンツ販売 | AIスキル講座・SNS運用代行・アプリ開発 |
