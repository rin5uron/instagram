# SNS×AI 自立プロジェクト

管理栄養士×IT×AIの掛け合わせで、自分のスキルと発信で稼ぐ道を作るプロジェクト。

---

## 背景

2019.3 管理栄養士取得。就職の動機はキャリアアップではなく、誰かの食生活の一部に関わることで自分の食体験を豊かにしたかったから。

2019.4 新卒で保育園の管理栄養士として就職。子どもの食に触れることで子どもの気づきや感性に刺激を受け、自分の人生や生活を見直すきっかけをもらい続けた。一方で、アナログな現場・デジタル化の遅れ・人手不足の構造的な問題を目の当たりにし、ITで仕組みをつくることで業界を根本から支えたいと感じた。

2023.4 グラフィックデザインへの関心からwebデザインスクールに入会。Adobeツールやプログラミングに触れたことで、2025年から本格的にプログラミング学習を開始。

仕事に追われ日々のときめきを大切にする時間が持てなかった。稼ぐためではなく、自分を大切にして生きるため、そのためのお金と手段が必要だと気づき、2025年12月に退職を決意。

プログラミング学習を続けながらマーケティングやSNS運用の大切さを実感し、2026年4月、このプロジェクトを開始した。

---

## アカウント

最初は管理栄養士としてのE-E-A-Tを確立しブランドにつなげる1アカウント運用を想定していた。しかし、マネタイズ設計と対象視聴者を見直した結果、AIスキル発信に軸足を移した。ただし管理栄養士としてのブランド力・撮影技術の獲得も並行して行いたいため、2アカウント同時運行中。マネタイズの方向性と視聴者ベネフィットは両アカウントで統一している。

| | [@ringo__note](https://www.instagram.com/ringo__note/) | [@ringonote_ai](https://www.instagram.com/ringonote_ai/) |
|---|---|---|
| テーマ | 栄養士×AI×食生活 | AI実験×検証 |
| コンセプト | ニートになった管理栄養士が、生活を崩さないためにGPTにごはんを丸投げするリアル記録 | AIに任せて、自分の時間を取り戻す実験中 |
| 視聴者ベネフィット | AIを使えば生活が整うかもと気づける・管理栄養士監修で信頼できる・自分でも真似できる | AIツールの使い方がわかる・自分でも試せる・時間を節約できる |
| マネタイズ | アフィリエイト・SNS運用代行・コンテンツ販売 | AIスキル講座・SNS運用代行・アプリ開発 |

## リサーチ方法

### 日常リサーチ（ネタ収集・感覚を磨く）

| 方法 | 使うタイミング | 見るポイント |
|---|---|---|
| 発見欄リサーチ | 広く収集したい時・テーマが決まっていない時 | 自分の発信領域のネタ・良い第一画像をスクショ |
| ハッシュタグ検索 | テーマが決まっている時・競合分析したい時 | 第一画像・構成・切り口・他と違う事例 |

### 検証リサーチ（仮説を立てて検証する）

「仮説 → 実験 → 結果 → 考察」を1issueで回す。

```
【検証】○○説
目的：〜を確かめる
仮説：〜のはずだ
変更点：〜と〜を比較
見る数値：視聴維持率・保存率・コメント率
```

- **1検証テーマ = 1issue**
- 検証記録はissueのコメントに積み上げる
- 完了したらclose
